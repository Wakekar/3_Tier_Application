Step 3 — Install Jenkins

Create a script.

vi jenkins.sh

Paste:

#!/bin/bash

sudo apt update -y

sudo apt install fontconfig openjdk-21-jre -y

java -version

sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key

echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc]" \
https://pkg.jenkins.io/debian-stable binary/ | \
sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null

sudo apt update

sudo apt install jenkins -y

sudo systemctl enable jenkins

sudo systemctl start jenkins

sudo systemctl status jenkins

Save

:wq

Give permission

chmod +x jenkins.sh

Run

./jenkins.sh

Verify

http://PUBLIC-IP:8080

Unlock Jenkins

sudo cat /var/lib/jenkins/secrets/initialAdminPassword

Step 4 — Install Docker (Jenkins Server)

Create the script

Paste your Docker installation script.

Make executable

Verify

sudo chmod 666 /var/run/docker.sock

Recommended (Production)

sudo usermod -aG docker $USER

newgrp docker

Verify

Step 5 — Install Trivy
sudo apt install wget gnupg -y

| gpg --dearmor \
| sudo tee /usr/share/keyrings/trivy.gpg >/dev/null

echo "deb [signed-by=/usr/share/keyrings/trivy.gpg] \
https://aquasecurity.github.io/trivy-repo/deb generic main" \
| sudo tee /etc/apt/sources.list.d/trivy.list

sudo apt update

sudo apt install trivy -y

Verify

trivy --version

Step 10 — Install kubectl

Install the latest stable version rather than the old 1.19 binary. For example:

Step 12 — Create EKS Cluster
eksctl create cluster \
--name=my-Aniket-EKS-5 \
--region=ap-south-1 \
--zones=ap-south-1a,ap-south-1b \
--version=1.30 \
--without-nodegroup

Associate IAM OIDC Provider (use the same cluster name consistently):    >>>>>>>>>>>>>>>>>>>>>

eksctl utils associate-iam-oidc-provider \
--region ap-south-1 \
--cluster my-Aniket-EKS-5 \
--approve

Create Node Group >>>>>>>>>>>>>>>>>>>>>>>>>>>>>

eksctl create nodegroup \
--cluster=my-Aniket-EKS-5 \
--region=ap-south-1 \
--name=node2 \
--node-type=c7i-flex.large \
--nodes=3 \
--nodes-min=2 \
--nodes-max=4 \
--node-volume-size=20 \
--ssh-access \
--ssh-public-key=Key \
--managed \
--asg-access \
--external-dns-access \
--full-ecr-access \
--appmesh-access \
--alb-ingress-access

Step 13 — Create Kubernetes Service Account

Create the webapps namespace first if it does not exist:

kubectl create namespace webapps

Then apply the following manifests in order:

ServiceAccount
Role
RoleBinding
kubectl apply -f serviceaccount.yaml
kubectl apply -f role.yaml
kubectl apply -f rolebinding.yaml

Verify

kubectl get sa -n webapps

kubectl get role -n webapps

kubectl get rolebinding -n webapps

_____________________________________________________________________________________________________________________________________________
Step 14 — Generate Service Account Token

For Kubernetes v1.24 and later, generate a token directly:

kubectl create token jenkins -n webapps

Copy the generated token.

In Jenkins:

Manage Jenkins → Credentials → Global
Add a new Secret Text credential.
Paste the token.
Use this credential in the Kubernetes plugin or pipeline.

If you specifically need a long-lived token secret, follow the Kubernetes documentation under "Create additional API tokens" for service accounts.

Troubleshooting
Issue	Solution
Jenkins not starting	>>>>     sudo systemctl status jenkins and sudo journalctl -u jenkins

Docker permission denied	>>>>   Add the user to the docker group and re-login (sudo usermod -aG docker $USER)

SonarQube not accessible	>>>>   Ensure port 9000 is open in the EC2 security group and the container is running (docker ps)

kubectl connection refused	>>>>   Verify kubeconfig with kubectl config current-context and kubectl cluster-info

EKS node group not joining	>>>   Check IAM permissions, VPC networking, and eksctl get nodegroup --cluster=my-Aniket-EKS-5

Jenkins cannot deploy to Kubernetes	>>>>   Verify the ServiceAccount, Role, RoleBinding, and the token stored in Jenkins credentials
